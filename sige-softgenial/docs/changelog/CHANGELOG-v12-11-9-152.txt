REMOCAO DE !important (12, so SVG)
---------------------------------
As regras .X svg{...!important} sao redundantes (seletor descendente 0,1,1 vence
a base .sg-svg-icon 0,1,0; tamanho via atributo HTML). Render identico.
!important do modulo: 625 -> 613.

IMPORTANTE: porque ficam 613 !important
---------------------------------------
O modulo foi escrito com um "cobertor" de !important em quase todas as
propriedades do escopo .sige-rh, para vencer o tema do wp-admin. Remove-los com
seguranca exige comparar contra os estilos do wp-admin (que nao existem fora de
um WordPress a correr). Por isso ficam para uma fase com verificacao em render
(screenshot antes/depois), nao para remocao estatica as cegas.
