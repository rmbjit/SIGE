bibliotecas para dentro (self-host) e criou a infra de enqueue. Este comeca a tirar
o codigo de interface de dentro do HTML: cria o mecanismo que substitui onclick,
faz a primeira vaga de migracao e protege-a com um gate de catraca.

MECANISMO DE DELEGACAO
================================================================
EDIT  assets/sige-ui.js
      - Novo despachante declarativo data-sige-act, ao lado do enhancer
        data-sige-confirm ja existente. Um unico ouvinte delegado (em fase de bolha)
        encontra o elemento com [data-sige-act], le o nome da funcao e dispara
        window[nome]. Se existir [data-sige-arg], passa-o como argumento; caso
        contrario passa o proprio elemento (equivalente ao this do onclick).
      - Corre em bolha para que o enhancer de confirmacao (em captura, com
        stopPropagation) seja sempre tratado primeiro.
