================================================================
CONTEXTO
================================================================
O CSP em enforcement (incremento final da Fase 4) bloqueia manipuladores de evento
inline (onclick). Esta versao converte as EXPRESSOES inline em onclick (logica
embutida, nao chamadas com argumentos) para funcoes nomeadas globais, ligadas pelo
despachante data-sige-act. Sequencia as vagas anteriores (v12.12.46 criou o
despachante; v12.12.50 os onclick simples; v12.12.51 os complexos com argumentos).

================================================================
FUNCOES NOMEADAS GLOBAIS (assets/sige-ui.js)
================================================================
Expostas em window (e nao em sigeUi) para o despachante as encontrar via window[accao]:

  sigeImprimirPagina()            -> window.print()                       (data-sige-noargs)
  sigeAlternarQuebraTexto(el)     -> alterna el.style.whiteSpace
  sigeAlternarClasseProximo(el)   -> alterna a classe 'open' do irmao seguinte
  sigeFecharPopupBackdrop(el)     -> sobe ate .sige-pro-popup-backdrop e remove
  sigeAlternarSidebar()           -> hamburguer: alterna sidebar/overlay/corpo (noargs)
  sigeFecharSidebar(el)           -> sobreposicao: remove sidebar/overlay(show)/corpo
  sigeAlternarSidebarMais(el)     -> mais opcoes: alterna conforme estado + aria-expanded

Cada funcao e fiel a expressao original. As que usavam this recebem o elemento (caso
por omissao do despachante); o hamburguer e o window.print nao precisam do elemento
(data-sige-noargs).
