UX - FUNDAÇÃO: UI KIT v1 (TOKENS + COMPONENTES + sigeUi)
- assets/sige-ui.css: tokens da marca em CSS custom properties
  (--sg-primario #0d1259, estados ok/erro/aviso/info, raios, sombras,
  anel de foco) + componentes canónicos namespaced: .sg-btn (primário/
  sec/perigo/ghost/sm), .sg-banner, .sg-card, .sg-badge, .sg-empty,
  .sg-modal, .sg-toast, .sg-spinner, .sg-table-wrap. Por ser tudo
  .sg-*, views não tocadas não mudam um pixel.
- assets/sige-ui.js: API global sigeUi com toast() (feedback não
  bloqueante, aria-live), confirm() (Promise, ESC/Enter/overlay, foco
  gerido, botão com o verbo da acção) e aCarregar(); enhancer
  declarativo [data-sige-confirm] para formulários sem JS por ecrã.
- includes/ui-kit.php: helpers sige_ui_banner()/sige_ui_empty() e
  carregamento auto-suficiente com dependência declarada do
  design system (zero alterações no admin-shell).
- docs/dev/UI-GUIA.md: o cânone (terminologia única Guardar/Remover/
  Pesquisar/Editar/Cancelar; diálogos nativos proibidos; confirmação
  destrutiva com o NOME do objecto; estado vazio com próxima acção;
  feedback humano em toda a acção; um botão primário por ecrã;
  pré-AO90; dd/mm/aaaa; 1.234,56 MT).
