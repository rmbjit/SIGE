RESUMO
switchTab e onclick com argumentos string via esc_js das vistas admin para o
despachante data-sige-act, continuando a preparar o CSP enforce do shell admin.
Duas conversoes que exigiam cuidado proprio.

SWITCHTAB (4 call-sites)
- Era switchTab(event, tabId) e usava event.target para marcar a aba activa.
- Refeito para switchTab(el), lendo o tabId do atributo data-tab que as abas ja
  possuem. Os 4 call-sites passam a data-sige-act (a via por omissao do despachante
  passa o proprio elemento).
- As abas sao div sem filhos, pelo que event.target era ja o elemento; comportamento
  identico. Confirmou-se que switchTab so e chamado por esses 4 onclick.

ARGUMENTOS STRING VIA ESC_JS (9 onclick)
- alocarProfessores, verAlunos, apagarTurma, verAcesso, apagarAluno, toggleStatus,
  removerUser, sigeAbrirAnular, plAbrirPagar passam a data-sige-act mais
  data-sige-args.
- Os argumentos sao serializados por esc_attr(wp_json_encode([...])):
  - wp_json_encode preserva os tipos (inteiros, decimais e cadeias);
  - esc_attr codifica para o atributo HTML (aspas, menor, e-comercial).
- Testou-se o round-trip ate JSON.parse com um valor dificil (aspa simples, aspa
  dupla, menor e e-comercial) e recuperou-se o valor exacto.
- Cada funcao alvo e global (funcao ou window.nome), encontrada pelo despachante via
  window. A ordem dos argumentos espelha a chamada original.
