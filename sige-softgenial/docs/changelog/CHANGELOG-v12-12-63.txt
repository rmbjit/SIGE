CHANGELOG - SIGE SoftGenial v12.12.63

CSP Report-Only no shell admin e lote de onclick admin
Data: 2026-06-23

RESUMO
Activacao do CSP Report-Only no shell admin e conversao de um grande lote de
onclick das vistas admin para o despachante data-sige-act. Passo decisivo para o
enforce do shell admin, feito com seguranca.

CSP REPORT-ONLY NO SHELL ADMIN
- Como o shell e toda a interface e nao e testavel em browser deste ambiente,
  seguiu-se o caminho profissional para uma superficie grande: Report-Only primeiro.
- Via admin_init e so nas paginas page=sige-app (antes do output, protegido por
  headers_sent e nao-ajax), envia-se um cabecalho
  Content-Security-Policy-Report-Only com apenas script-src self mais nonce por
  pedido.
- Report-Only NAO bloqueia nada: a consola do browser passa a reportar as violacoes
  reais (handlers inline e scripts sem nonce) que faltam tratar antes do enforce.
- So script-src e restringido; os restantes tipos de recurso ficam sem restricao,
  para a consola reportar apenas o que interessa.

FICHEIRO CANONICO
- Os 2 onclick do finance-core estao em sige_desp_print_page, uma pagina standalone
  de impressao com DOCTYPE proprio, fora do shell admin, pelo que nao caem sob este
  CSP nem foram tocados.

  gerirHorario por inteiro; anularLote sem argumentos; carregarHistorico com
  booleano; fecho de popup backdrop via sigeFecharPopupBackdrop.
- 3 com dois wrappers novos: sigeAlternarDisplay (alternar a visibilidade por id,
