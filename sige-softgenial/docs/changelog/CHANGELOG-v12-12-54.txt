Canal: validated-feature

================================================================
CONTEXTO
================================================================
O CSP em enforcement (incremento final da Fase 4) bloqueia manipuladores de evento
inline (onclick). Esta versao reescreve as ULTIMAS cadeias jQuery e funcoes
imediatamente invocadas (IIFE) em onclick para vanilla, em funcoes nomeadas. Conclui
os onclick em ficheiros limpos: nao resta nenhum onclick jQuery ou IIFE nessas vistas.
Sequencia as vagas anteriores (v12.12.46 a v12.12.53).

================================================================
FUNCOES NOMEADAS VANILLA (co-localizadas nas vistas)
================================================================
Definidas no script da propria vista e expostas em window (o despachante encontra-as
via window[accao]):

  admin/whatsapp_central-view.php
    window.sigeReabrirPainelPendentes()
      -> querySelector('.wppc-pending-panel'); removeAttribute('open');
         setTimeout(setAttribute('open',''), 100)   [fiel a IIFE original]

  admin/academic/matriz-view.php
    window.sigeFecharModalClone()
      -> getElementById('modal-clone'): display none, aria-hidden true;
         se nenhum .sige-modal estiver visivel (offsetWidth/offsetHeight/getClientRects,
         como o :visible do jQuery), remove a classe sige-modal-open do corpo

================================================================
CONVERSAO DE ONCLICK (2 trocas)
================================================================
EDIT  admin/whatsapp_central-view.php
      onclick="(function(){...querySelector('.wppc-pending-panel')...})()"  (em template JS)
      -> data-sige-act="sigeReabrirPainelPendentes" data-sige-noargs

EDIT  admin/academic/matriz-view.php
      onclick="jQuery('#modal-clone').hide().attr('aria-hidden','true'); if (!jQuery('.sige-modal:visible').length) jQuery('body').removeClass('sige-modal-open');"
      -> data-sige-act="sigeFecharModalClone" data-sige-noargs

EDIT  tools/check-inline-frontend.php
      - SIGE_INLINE_ONCLICK_MAX de 164 para 162. style 2051 e script 81 inalterados.

CONCLUSAO: zero onclick jQuery ou IIFE em ficheiros limpos. Os restantes onclick estao
em ficheiros com janela autonoma, em popups ou em canonicos.
