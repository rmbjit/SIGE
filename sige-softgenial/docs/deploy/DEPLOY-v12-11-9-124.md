# DEPLOY - SIGE SoftGenial v12.11.9.124 (auditoria de design: jardim_saude)

## O que muda nesta versão (resumo de 30 segundos)
Auditoria de design do registo de saúde do jardim de infância. Os nomes
das crianças destacam-se, os detalhes recuam para texto leve. As cores de
estado de saúde (verde = saudável, vermelho = alerta/alergia, laranja =
aviso) mantêm-se. Cantos e sombras consistentes. Sem alterações de
lógica nem de dados médicos.

## Instalação
1. wp-admin > Plugins > Adicionar novo > Carregar plugin;
2. Enviar sige-softgenial-v12.11.9.124.zip;
3. "Substituir o plugin actual" > Activar.

Ordem: teste.softgenial primeiro, depois demo > restantes.

## Pós-deploy imediato (1 minuto)
Abrir o registo de Saúde do jardim: os cartões das crianças com nome
destacado, detalhes em texto leve. As cores de estado (saudável verde,
alerta/alergia vermelho) corretas. Registar/editar informação de saúde
continua a funcionar.

## Rollback
ZIP da v12.11.9.123 > "Substituir". Sem migrações: rollback instantâneo.
