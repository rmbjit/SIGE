## Resumo
Release de limpeza de engenharia: zero alterações a regras financeiras ou académicas.

ortografia pré-AO90 no texto visível, elimina travessões do código, blinda os

## Passos de deploy (Hostinger/CloudPanel, por subdomínio)
1. Backup: exportar a pasta actual do plugin e um dump da base de dados.
2. Desactivar o plugin SIGE SoftGenial no wp-admin (não desinstalar).
3. Substituir a pasta `wp-content/plugins/sige-softgenial/` pelo conteúdo do ZIP
   (apagar a antiga e enviar a nova; não fazer merge por cima, porque esta versão
   REMOVE ficheiros da raiz e o órfão admin/academic/sedw9tqQh).
4. Reactivar o plugin.
5. Abrir Estado do Sistema e confirmar versão 12.11.9.89 e build alinhado.
6. Correr o checklist de testes live (docs/qa/TESTES-LIVE-v12-11-9-89.md).

## Pontos de atenção
- O ZIP novo tem MENOS ficheiros na raiz do que o antigo: é esperado. O histórico
  vive agora em docs/.
- Os smoke tests antigos em tools/ são instantâneos congelados da sua release;
  o gate vivo desta build é `php tools/smoke-release-gate.php` (49 verificações).
- Notas de fecho de caixa criadas a partir desta versão usam o cabeçalho
  "FECHO DE CAIXA COM RECONCILIAÇÃO"; registos antigos mantêm o texto antigo.
  O parser usa o marcador [SIGE_RECON_V1], que não mudou.
- uninstall.php nunca apaga dados da escola (política documentada no ficheiro).

## Rollback
Repor a pasta do plugin a partir do backup do passo 1 e reactivar. Não há
migração de base de dados nesta release; o rollback é apenas de ficheiros.
