# DEPLOY - SIGE SoftGenial v12.11.9.117 (auditoria de design: boletim)

## O que muda nesta versão (resumo de 30 segundos)
Auditoria de design do boletim de aproveitamento. As disciplinas e notas
destacam-se, qualificadores (Positiva/Negativa) recuam para texto leve.
O MAIS IMPORTANTE: as cores das notas (verde = positiva, vermelho =
negativa, e o código de cores por faixa de nota) foram PRESERVADAS - a
leitura do aproveitamento é a mesma. O boletim impresso sai igual. Sem
alterações de cálculo de médias nem de dados.

## Instalação
1. wp-admin > Plugins > Adicionar novo > Carregar plugin;
2. Enviar sige-softgenial-v12.11.9.117.zip;
3. "Substituir o plugin actual" > Activar.

Ordem: teste.softgenial primeiro, depois demo > restantes.

## Pós-deploy imediato (3 minutos - documento sensível)
1. Abrir o Boletim de um aluno: disciplinas e notas destacadas,
   situação em texto leve;
2. As cores das notas: positivas em verde, negativas em vermelho - o
   código de cor por nota deve estar correto;
3. Média final em destaque;
4. CRÍTICO: imprimir/gerar o boletim (Aproveitamento) - deve sair IGUAL
   a antes, com as cores das notas corretas.
