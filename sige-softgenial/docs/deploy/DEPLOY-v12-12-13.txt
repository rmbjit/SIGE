DEPLOY - SIGE SoftGenial v12.12.13 (Painel de controlo de seguranca MFA, so super admin)
Base: v12.12.12. Sem migracao de base de dados. Sem alteracao de regras de calculo.

O QUE MUDA
- Novo ecra "Seguranca (MFA)" em Definicoes, so para o administrador WordPress real, para ligar/desligar o step-up, a reposicao automatica e o modo estrito, e escolher os perfis abrangidos, tudo a partir do painel (sem codigo/CLI/BD).
- O Admin IT (sige_admin_ti) e os outros perfis nativos do SIGE nao veem nem acedem a este ecra.
- Em producao, os avisos do PHP (deprecations) deixam de aparecer no wp-admin (continuam no log). Removida a faixa amarela strip_tags.

PASSOS
1. Backup do plugin e da base de dados (rotina habitual).
2. Substituir a pasta do plugin pela desta versao (ou actualizar via ZIP). Os 7 ficheiros canonicos da raiz mantem-se.
3. Confirmar a versao: cabecalho do plugin, SIGE_VERSION e BUILD.json em 12.12.13.
4. Sem passos de base de dados.

COMO USAR (so o administrador WordPress real)
1. Entrar como administrador WordPress (perfil administrator). Ir a Definicoes, Seguranca (MFA).
2. Marcar/desmarcar: Step-up, Reposicao automatica, Modo estrito. Escolher os Perfis abrangidos.
3. Guardar. As alteracoes ficam registadas na auditoria; desligar o step-up gera um evento proprio.
4. Se ja tinha ligado o step-up por mu-plugin/CLI/BD, pode agora apagar esse mu-plugin: o ecra passa a ser a forma normal de gerir.

NOTAS DE ACESSO
- So o perfil administrator (ou super admin de multisite) ve e usa este ecra. Os perfis SIGE (incluindo Admin IT) sao recusados no menu, no render e na gravacao.
- Se o dono tiver administrator e tambem um perfil SIGE, continua a aceder (administrator tem prioridade).

OPCOES
- sige_admin_hide_php_notices (defeito on): controla a supressao da exibicao de avisos do PHP no wp-admin em producao. Para voltar a ver os avisos no ecra (por exemplo, ao depurar), pode desligar esta opcao ou activar WP_DEBUG.

REVERSAO
- O ecra so le/grava opcoes; nao ha estado novo a reverter. Para repor o comportamento anterior, basta usar o ecra (ou a opcao/constante) para desligar o que tiver ligado.

VERIFICACAO RAPIDA
- Como administrador WordPress: Definicoes > Seguranca (MFA) aparece e permite guardar.
- Como utilizador com perfil Admin IT (sige_admin_ti) ou outro nativo do SIGE: o item Seguranca (MFA) NAO aparece; um acesso directo a options-general.php?page=sige-mfa-settings e recusado.
- Apos guardar, confirmar no registo de seguranca os eventos mfa_settings_change (e mfa_stepup_disabled se desligou o step-up).
