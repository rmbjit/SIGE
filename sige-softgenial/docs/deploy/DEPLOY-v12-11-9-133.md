# DEPLOY - SIGE SoftGenial v12.11.9.133 (auditoria de design: jardim_presencas)

## O que muda nesta versão (resumo de 30 segundos)
Auditoria de design do registo de presenças do jardim. Os nomes das
crianças destacam-se, os badges de estado recuam para ênfase. As cores de
estado (verde = presente, laranja = atraso, vermelho = falta, azul =
justificada) mantêm-se. Cantos e sombras consistentes. Sem alterações de
lógica nem de dados.

## Instalação
1. wp-admin > Plugins > Adicionar novo > Carregar plugin;
2. Enviar sige-softgenial-v12.11.9.133.zip;
3. "Substituir o plugin actual" > Activar.

Ordem: teste.softgenial primeiro, depois demo > restantes.

## Pós-deploy imediato (1 minuto)
Abrir as Presenças do jardim: os nomes destacados, badges de estado com
as cores corretas (presente verde, atraso laranja, falta vermelho,
justificada azul). Marcar presença continua a funcionar.
