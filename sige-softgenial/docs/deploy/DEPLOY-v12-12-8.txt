PASSOS DE DEPLOY
1. Fazer backup do plugin actual (pasta wp-content/plugins/sige-softgenial).
2. Substituir a pasta do plugin pelo conteudo deste ZIP.
3. Nao ha migracao de base de dados nem alteracao de esquema.
4. Limpar cache de objecto/opcoes se aplicavel.
5. Verificar versao activa: 12.12.8 (Plugins ou rodape do SIGE).

VERIFICACAO POS-DEPLOY (mono-escola, caso actual)
- Abrir uma view de escrita (ex.: lancar notas, guardar config financeira) e
  confirmar funcionamento normal: o resolvedor devolve a escola unica.
- Guardar um pagamento/lancamento e confirmar o fluxo habitual.

NOTA MULTI-ESCOLA (futuro)

ROLLBACK
