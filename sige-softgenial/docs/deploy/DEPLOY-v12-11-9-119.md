# DEPLOY - SIGE SoftGenial v12.11.9.119 (auditoria de design: minhas_turmas)

## O que muda nesta versão (resumo de 30 segundos)
Auditoria de design do ecrã "Minhas Turmas" (o dos cartões com ícones que
ajustámos antes). Agora, além dos ícones proporcionais, os textos têm
hierarquia: os números destacam-se, os rótulos são secundários, as
legendas recuam. As cores de estado (verde=completo, laranja=parcial,
vermelho=pendente) mantêm-se. Sem alterações de lógica nem de dados.

## Instalação
1. wp-admin > Plugins > Adicionar novo > Carregar plugin;
2. Enviar sige-softgenial-v12.11.9.119.zip;
3. "Substituir o plugin actual" > Activar.

Ordem: teste.softgenial primeiro, depois demo > restantes.

## Pós-deploy imediato (1 minuto)
Abrir Minhas Turmas: os KPIs (Turmas, Alunos, Completas) com os números
destacados, rótulos e legendas recuados. Ícones proporcionais (já de
antes). Cores de estado das turmas (completo/parcial/pendente) corretas.

## Rollback
ZIP da v12.11.9.118 > "Substituir". Sem migrações: rollback instantâneo.
