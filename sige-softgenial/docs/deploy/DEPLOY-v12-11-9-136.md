# DEPLOY - SIGE SoftGenial v12.11.9.136 (auditoria de design: notas)

## O que muda nesta versão (resumo de 30 segundos)
Auditoria de design do lançamento de notas. Os títulos e nomes destacam-se,
os subtítulos recuam para texto leve. As notas negativas mantêm-se a
vermelho. Os campos de input de nota mantêm-se reconhecíveis. SEM
alterações ao cálculo de notas, médias, ou regras académicas.

## Instalação
1. wp-admin > Plugins > Adicionar novo > Carregar plugin;
2. Enviar sige-softgenial-v12.11.9.136.zip;
3. "Substituir o plugin actual" > Activar.

Ordem: teste.softgenial primeiro, depois demo > restantes.

## Pós-deploy imediato (2 minutos) - CRÍTICO (académico)
1. Abrir o Lançamento de notas de uma turma: título e nomes destacados,
   subtítulo em texto leve;
2. As notas negativas (abaixo de 10) a VERMELHO;
3. Os campos de input de nota reconhecíveis e editáveis;
4. CRÍTICO: lançar uma nota de teste - guarda corretamente, médias
   calculadas certas (não mudaram).

## Rollback
ZIP da v12.11.9.135 > "Substituir". Sem migrações: rollback instantâneo.
