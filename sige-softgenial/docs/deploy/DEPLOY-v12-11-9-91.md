# DEPLOY - SIGE SoftGenial v12.11.9.91 (Sprint 2)

## O que muda nesta versão (resumo de 30 segundos)
Dois módulos novos: **Presenças** (mapa de assiduidade derivado
automaticamente da Portaria, com correcção humana auditada) e
**Pagamentos M-Pesa** (canal completo com conciliação automática, OFF por
defeito até preencheres credenciais). Duas tabelas novas criadas sozinhas
pela migração. Zero alterações a regras financeiras ou académicas: a
conciliação M-Pesa regista pagamentos pela MESMA função do balcão.

## Instalação (igual a sempre)
1. wp-admin > Plugins > Adicionar novo > Carregar plugin;
2. Enviar sige-softgenial-v12.11.9.91.zip;
3. WordPress pergunta: escolher "Substituir o plugin actual";
4. Activar e abrir QUALQUER página do admin uma vez: a migração de schema
   cria as tabelas sige_presencas_excecoes e sige_mpesa_transacoes.

Ordem recomendada: demo > cicasacolorida > lmuhalaze > malisa.

## Presenças: funciona logo (se a Portaria estiver em uso)
- Menu Académico > Presenças > escolher turma: o mapa do mês aparece
  derivado das leituras de crachá já existentes em sige_acessos;
- Escolas SEM scanner: o mapa funciona 100% por marcação manual
  (clicar célula > "Presente (marcação manual)");
- Hora de corte do atraso (defeito 07:30), ajustar se preciso:
```
wp option update sige_presencas_hora_corte "07:15"
```

## M-Pesa: OFF até decidires ligar
1. Criar conta em developer.mpesa.vm.co.mz e obter API Key, Public Key e
   Service Provider Code (sandbox primeiro);
2. Menu Financeiro > Pagamentos M-Pesa > preencher credenciais e escolher
   ambiente Sandbox > Guardar;
3. Copiar o endereço do webhook e registá-lo no portal da Vodacom;
4. Comunicar às famílias: pagar para o código da escola usando o
   NÚMERO DE PROCESSO do aluno como referência (o mesmo do crachá).
Enquanto o ambiente estiver em "Desligado", o módulo não faz nada.

## Rollback
Carregar o ZIP da v12.11.9.90 > "Substituir". As duas tabelas novas ficam
na base (vazias ou não) sem qualquer efeito na versão anterior; nenhuma
tabela existente foi alterada. Rollback instantâneo e seguro.
