# DEPLOY v12.11.9.83 - Histórico Financeiro Documento Administrativo + UX PRO

**Pacote:** `sige-softgenial-v12_11_9_83-historico-financeiro-documento-administrativo-ux-pro.zip`
**Tipo:** pacote completo do plugin (instalação integral, nunca por blocos).
**Base validada:** v12.11.9.82.

## Instalação (Hostinger File Manager, sem SSH)
1. Faça uma cópia de segurança da pasta actual do plugin (`wp-content/plugins/sige-softgenial/`) antes de substituir.
2. No File Manager, navegue até `wp-content/plugins/`.
3. Remova (ou renomeie para `sige-softgenial_bkp_v82/`) a pasta `sige-softgenial/` existente.
4. Carregue o ZIP `sige-softgenial-v12_11_9_83-...zip` para `wp-content/plugins/` e extraia. Deve ficar `wp-content/plugins/sige-softgenial/` (a pasta de topo já vem dentro do ZIP).
5. Em cada escola/subdomínio, confirme no Painel que a versão activa é **12.11.9.83**.
6. Limpe caches (LiteSpeed/Cloudflare e qualquer cache de página) para que o CSS do documento e do painel seja recarregado.

> O SigeHub no site-mãe continua a controlar licenças/cobrança. Não é preciso reactivar licenças por causa desta actualização.

## Verificação rápida pós-instalação
1. **Extractos / Caixa**
   - Abra Financeiro → Extractos / Caixa.
   - Clique no separador "Histórico de aluno" **sem** seleccionar aluno: o separador deve **acender**, o hero deve mudar para "Histórico de aluno" e mostrar o convite "Seleccione um aluno...". (Antes não acontecia nada.)
   - Seleccione um aluno: o painel de transferência mostra "Abrir documento / PDF" e "Baixar Excel". Ao clicar em "Abrir documento / PDF", o botão indica "A abrir..." e o documento abre numa nova aba.
2. **Documento (PDF/Guardar)**
   - Dentro do documento, confirme o aspecto de folha administrativa (cabeçalho institucional, "Identificação do aluno", "Quadro da situação financeira", Parecer, assinaturas Tesouraria/Secretaria/Direcção).
   - Use "Guardar PDF / Imprimir": deve sair em A4 retrato, sem aspecto de dashboard.
3. **Excel**
   - Em "Baixar Excel", abra o ficheiro: quatro folhas (Resumo 360, Pagamentos, Obrigacoes, Metodos 360), faixas azul-marinho, grelha oculta, valores em `#,##0.00 MT`, dívida a vermelho e crédito a verde.
