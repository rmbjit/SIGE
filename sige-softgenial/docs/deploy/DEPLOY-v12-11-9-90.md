## Instalação (igual a sempre)
1. wp-admin > Plugins > Adicionar novo > Carregar plugin;
2. Enviar sige-softgenial-v12.11.9.90.zip;
3. WordPress pergunta: escolher "Substituir o plugin actual";
4. Activar. Dados, configurações e licença ficam intactos.

Ordem recomendada: demo > cicasacolorida > lmuhalaze > malisa.

## Activações opcionais (quando decidires, sem pressa)

### 2FA por email (recomendado começar por UM utilizador de teste)
```
wp option update sige_2fa_email on
```
Desligar: `wp option update sige_2fa_email off`
Emergência absoluta (wp-config.php): `define('SIGE_2FA_OFF', true);`

### Relatório mensal automático à Direcção
```
wp option update sige_relatorio_mensal_email on
wp option update sige_relatorio_mensal_destinatarios "director@escola.mz, geral@escola.mz"
```
(vazio = vai para o email de administração do site)

## Operações novas a instalar na VPS (uma vez, fora do plugin)

   (15 minutos; inclui teste de restauro semanal automático);
2. **Git + CI**: seguir docs/dev/GIT-CI.md (10 minutos; primeiro push
   e o ZIP passa a nascer do CI).

## Migração de status (opcional, com backup feito)
```
wp eval-file wp-content/plugins/sige-softgenial/tools/migrar-status-canonico.php
```
(dry-run: só mostra; para aplicar, acrescentar --aplicar e escrever CONFIRMO)

## Rollback
Plugins > Adicionar novo > carregar o ZIP da v12.11.9.89 > "Substituir".
Nada nesta versão altera schema de dados: rollback é instantâneo e seguro.
As options novas (sige_2fa_email, etc.) ficam inertes na versão anterior.
