# DEPLOY - SIGE SoftGenial v12.11.9.141 (auditoria de design: auditoria_notas)

## O que muda nesta versão (resumo de 30 segundos)
Auditoria de design do rastreio/auditoria de notas. As descrições dos
registos destacam-se, os metadados recuam para texto leve. As cores por
módulo (Notas laranja, Acesso vermelho, Alunos verde, etc.) e os registos
de erro (vermelho) mantêm-se. Sem alterações de lógica nem de dados.

## Instalação
1. wp-admin > Plugins > Adicionar novo > Carregar plugin;
2. Enviar sige-softgenial-v12.11.9.141.zip;
3. "Substituir o plugin actual" > Activar.

Ordem: teste.softgenial primeiro, depois demo > restantes.

## Pós-deploy imediato (1 minuto)
1. Abrir a Auditoria de notas: descrições destacadas, metadados em texto
   leve;
2. As cores por módulo (Notas, Acesso, Alunos, etc.) corretas;
3. Os registos de ERRO destacados (vermelho).
