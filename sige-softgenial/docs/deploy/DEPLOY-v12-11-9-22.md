# DEPLOY - SIGE SoftGenial v12.11.9.22
## Barra de Topo com Avatar + App-Bar Mobile

**Tipo:** UI / App Shell / Mobile UX
**Risco:** Baixo (camada visual + markup da barra; sem formulas/dados/permissoes)
**Canal:** teste -> validar -> producao

---

### 1. Instalacao (Hostinger File Manager / cPanel)
1. *Plugins* -> **desactivar** "SIGE SoftGenial".
2. Apagar `wp-content/plugins/sige-softgenial/`.
3. Carregar e extrair `sige-softgenial-v12_11_9_22.zip` (mantem a pasta de topo `sige-softgenial/`).
4. **Reactivar**.
5. **Limpar cache** + no browser **Ctrl+Shift+R** (a versao nova ja renova o cache do CSS).

> Multi-tenant: aplica-se a todos os clientes. Sem migracoes de base de dados.

---

### 2. O que validar

**Desktop (?page=sige-app):**
- [ ] A barra de topo mostra, a direita, o **avatar** (foto ou iniciais no circulo violeta) com **nome + papel**.
- [ ] Ao rolar a pagina, a **barra fica fixa no topo** do conteudo.

**Telemovel (abrir no telemovel ou DevTools modo movel):**
- [ ] A barra de topo e uma **app-bar fixa no topo**: botao de menu a esquerda, titulo no meio, avatar a direita.
- [ ] O botao de menu abre/fecha a barra lateral; o **avatar** aparece como circulo.
- [ ] Os **KPIs** (Alunos, Docentes, Pagamentos, Divida) aparecem em **2 colunas**; os **atalhos** tambem.
- [ ] Os botoes do heroi (Registar Pagamento / Gerir Alunos) ocupam a largura.
- [ ] Nao ha um botao de menu "a flutuar" solto sobre o conteudo (esta dentro da barra).

**Tema personalizado (opcional):**
- [ ] Mudar a cor primaria da escola e confirmar que o circulo do avatar e a barra seguem essa cor.

---

### 3. Reverter
Reinstalar `sige-softgenial-v12_11_9_21.zip`. Sem efeitos em dados.

---

### 4. Notas
- A foto do avatar vem do Gravatar associado ao email do utilizador. Se nao existir
  (ou a rede bloquear o Gravatar), aparecem as iniciais - comportamento desejado.
- Esta entrega trata a app shell (barra/menu, que envolve TODOS os ecras) e o
  Painel no movel. Os restantes ecras continuam a beneficiar da unificacao de cor
  ja entregue; afinacoes mobile especificas de outros modulos podem seguir a seguir.
