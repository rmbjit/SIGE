# DEPLOY - SIGE SoftGenial v12.11.9.138 (auditoria de design: core-status)

## O que muda nesta versão (resumo de 30 segundos)
Auditoria de design do diagnóstico do sistema. Os nomes das verificações
destacam-se, os detalhes recuam para texto leve. As cores de estado (verde
= OK, laranja = aviso, azul = período de graça) mantêm-se. Sem alterações
de lógica nem de dados.

## Instalação
1. wp-admin > Plugins > Adicionar novo > Carregar plugin;
2. Enviar sige-softgenial-v12.11.9.138.zip;
3. "Substituir o plugin actual" > Activar.

Ordem: teste.softgenial primeiro, depois demo > restantes.

## Pós-deploy imediato (1 minuto)
Abrir o Estado do sistema/Core status: os nomes das verificações
destacados, detalhes em texto leve, e os estados (OK verde, Aviso laranja)
com as cores corretas. Os valores de diagnóstico continuam a refletir o
estado real.
