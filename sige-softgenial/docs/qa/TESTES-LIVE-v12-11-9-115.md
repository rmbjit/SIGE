# TESTES LIVE - v12.11.9.115 (auditoria de design: aluno-portal)

Fazer em teste.softgenial.edu.mz. Tempo: ~4 minutos.
Portal EXTERNO (famílias) - testar bem. Console: zero vermelhos.

## 1. Header do aluno (1 min)
1. O NOME do aluno deve ser o elemento mais forte;
2. Dados de turma (classe, turma, número) em texto LEVE, recuados.

## 2. KPIs (1 min)
1. Idade, Média, Total Pago: os VALORES destacam-se, rótulos
   secundários;
2. Cores corretas (verde para média/pago, etc.).

## 3. Tema da escola (1 min)
1. Se a escola tiver cor personalizada configurada, o portal deve
   refleti-la (KPIs, destaques);
2. Sem personalização, usa o roxo padrão.

## 4. Conteúdo e funcionalidade (1 min)
1. Notas/boletim, financeiro, presenças: secções carregam e legíveis;
2. Se houver bloqueio por dívida, a mensagem aparece corretamente.

## Critério de aprovação
Nome destaca-se, dados recuam, KPIs legíveis, tema da escola respeitado,
secções funcionam, console limpo = v115 validada.
