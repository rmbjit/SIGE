# RC7 v12.16.0 Mobile Header Hotfix

## Situacao

Durante a validacao em staging do RC6, o acesso do Professor a Minhas Turmas ficou funcional, mas o header mobile ficou visualmente apertado e estranho. A captura mostra excesso de elementos na mesma linha: menu, logotipo, marca, Ano Lectivo e avatar.

## Risco

Classificacao: P2 bloqueador de acabamento antes do ZIP final.

O problema afecta usabilidade e percepcao de qualidade em mobile, mas nao altera dados, financeiro, academico, permissao ou tenant isolation.

## Decisao tecnica

A solucao segura foi aplicar um hotfix tardio e localizado no shell global para mobile:

- manter o header em tres zonas: menu, marca, avatar;
- esconder pesquisa global no header mobile;
- esconder o chip Ano Lectivo no header mobile;
- esconder nome/cargo do utilizador no header mobile;
- manter apenas o avatar como identificacao compacta;
- usar apenas tokens de design system;
- nao alterar HTML, rotas, permissoes ou dados.

## Rollback

Reverter o bloco identificado por `sige-mobile-header-professor-rc7-v121600` em `includes/admin-shell.php` e remover os dois gates RC7 do corredor. O rollback nao toca dados.

## Resultado esperado

No mobile, o header deve apresentar:

- menu a esquerda;
- logotipo e SoftGenial ao centro;
- avatar a direita;
- sem chip Ano Lectivo no topo;
- sem pesquisa global no topo;
- sem aperto visual.
